## Post-lab answers

**Q1. Why is `.gitignore` important for a Java/Maven project?**  
It prevents generated and machine-specific files such as `target/`, compiled `.class` files, and IDE metadata from being tracked. This keeps the repository focused on source code and project files.

**Q2. Difference between `git add` and `git commit`?**  
`git add` stages selected changes for the next snapshot. `git commit` saves the staged snapshot in the local Git repository with a message.

**Q3. Benefit of a feature branch over committing directly to `main`?**  
A feature branch isolates new work so it can be developed and tested separately, then reviewed and merged into `main` when ready.
